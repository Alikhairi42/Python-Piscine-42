## 📖 About

The **Python Piscine** is an intensive training at 42 that teaches the fundamentals
of Python through daily modules. Each module (or day) introduces new concepts
and ends with a set of exercises that must be completed and peer-evaluated.

This repository contains my solutions for **Modules 00 to 08**.

## 🧠 What I Learned

**Module 00 — Basics**
Learned the core syntax of Python: variables, expressions, functions, `if/else`, loops and recursion.

**Module 01 — Functions & OOP intro**
Learned to write clean functions with type hints and docstrings, and discovered classes and objects.

**Module 02 — Exceptions**
Learned to handle errors with `try/except/finally`, raise my own custom exceptions, and write defensive code.

**Module 03 — Data structures**
Learned to use lists, dicts, sets and tuples, and to transform and analyze data with simple scripts.

**Module 04 — Files & streams**
Learned to read and write files, work with streams, and handle archives.

**Module 05 — Pipelines**
Learned to chain several processing steps together so data flows through composable stages.

**Module 06 — Packages & imports**
Learned how to structure a project in packages, manage imports, and keep module dependencies clean.

**Module 07 — OOP design**
Learned inheritance, composition, interfaces and abstract classes by modeling a card game.

**Module 08 — Advanced scripting**
Learned more advanced Python concepts and applied them in continuation exercises.

## ⚙️ Requirements

- Python 3.10 or higher
- `pip` and `venv`
- A Unix-like environment (Linux / macOS)

## 🚀 Getting Started

```bash
# Clone the repository
git clone <your-repo-url> python-piscine
cd python-piscine

# (Optional) create a virtual environment
python3 -m venv venv
source venv/bin/activate

# Install dependencies if a module needs them
pip install -r requirements.txt
```

Go into the exercise folder and run the script with Python:

cd module00/ex00

---

## ✅ Norm & Rules

- Code follows the **PEP 8** style guide (checked with `flake8`).
- Every function and class is documented with docstrings.
- Type hints are used where required by the subject.
- No forbidden functions or libraries as specified in each subject.

Check style with:

```bash
flake8 .
```

---

## 🧪 Testing

Each exercise can be tested by running it directly and comparing the output
with the expected output in the subject. Where available, tests can be run with:

```bash
python3 -m pytest
```
